# Fichiers d'exemple des tutoriels

- `planetes-periode-distance.csv` : distance moyenne au Soleil (demi-grand axe, 10^6 km) et période
  orbitale sidérale (jours) des huit planètes, de Mercure à Neptune, dans cet ordre. Valeurs recopiées
  sans modification de la *Planetary Fact Sheet* de la NASA (NSSDCA, D. R. Williams),
  https://nssdc.gsfc.nasa.gov/planetary/factsheet/ , consultée le 2026-10-22. Données factuelles
  publiées par une agence fédérale américaine ; source à citer dans les crédits.
