# Apprendre avec les tutoriels

Les tutoriels se font **dans le logiciel lui-même**. Chaque étape vous demande une action réelle et **se valide toute seule** dès qu'ANTARES constate qu'elle est faite. Rien n'est simulé.

Suivis dans l'ordre, ils couvrent toutes les fonctions du logiciel en une heure environ.

## Lancer un tutoriel

- **Aide > Tutoriels**, puis le tutoriel voulu ;
- ou la page d'**Accueil** (**Aide > Accueil…**), colonne *Apprendre*.

Certains tutoriels ouvrent un **projet d'exemple** (vide ou issu d'un modèle). Si votre projet en cours a des modifications non enregistrées, ANTARES propose d'abord de l'enregistrer. Vos fichiers ne sont jamais modifiés par un tutoriel.

## Le panneau Tutoriel

- Le titre de l'étape et ce qu'il faut faire.
- **Montre-moi** fait clignoter la zone de l'interface concernée.
- **Un indice ?** donne une piste supplémentaire quand elle existe.
- Un bouton d'action apparaît parfois, par exemple pour importer le fichier de données d'exemple.
- **◀ Précédent** et **Suivant ▶** permettent de revenir en arrière ou de passer une étape.
- Une coche ✓ marque les étapes validées ; la barre indique la progression.

Les tutoriels terminés sont cochés dans le menu et sur la page d'accueil.
