# Provenance et licences

Chaque image, son, fichier de données ou séquence importé reçoit une **fiche de provenance**. Elle sert à produire des crédits exacts et à éviter de publier une ressource sans en avoir le droit.

## La fiche

Elle s'ouvre après chaque import ; dans l'onglet **Ressources** de la Bibliothèque, un double-clic la rouvre.

| Champ | À remplir |
|---|---|
| Auteur | personne ou organisme, par exemple « NASA/JPL-Caltech » |
| Source | adresse web ou référence précise |
| Licence | choix dans la liste ci-dessous |
| Attribution requise | cochée si la licence impose de citer l'auteur |
| Redistribution autorisée | décochée si vous n'avez pas le droit de publier la ressource |

**Plus tard** laisse la ressource en *provenance manquante*.

## Licences proposées

| Licence | Citer l'auteur ? | Publier ? |
|---|---|---|
| Œuvre personnelle (auteur du projet) | non | oui |
| CC0 1.0 — domaine public volontaire | non | oui |
| Domaine public | non | oui |
| CC BY 4.0 — attribution | oui | oui |
| CC BY-SA 4.0 — attribution, partage identique | oui | oui, sous la même licence |
| CC BY-NC 4.0 — pas d'usage commercial | oui | oui, sans usage commercial |
| Propriétaire / usage personnel | non | **non** |
| Autre (préciser dans la source) | oui | à vérifier |

## Les statuts

- **complète** : licence et auteur ou source renseignés, publication autorisée ;
- **provenance manquante** : licence absente, ou ni auteur ni source ;
- **non redistribuable** : la licence interdit la publication.

À l'export, chaque ressource utilisée dans la scène et dont le statut n'est pas *complète* est signalée par un **avertissement**. L'export n'est pas bloqué : c'est à vous de décider en connaissance de cause.

## L'inventaire

**Fichier > Inventaire des licences et crédits…** liste toutes les ressources du projet, leur statut, les scènes qui les utilisent et le texte des crédits généré. Double-clic sur une ligne pour corriger la fiche.

Voir aussi [Crédits](credits.md).
