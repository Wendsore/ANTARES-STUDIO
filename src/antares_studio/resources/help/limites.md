# Ce qui n'est pas encore possible

ANTARES Studio est en version de développement. Voici, honnêtement, ce qu'il ne fait pas encore.

## Création et animation

- Choisir l'interpolation clé par clé dans la Timeline : les clés posées à la main sont linéaires ; seules les animations prédéfinies proposent accélération et décélération.
- Éditer à la souris les sommets d'un polygone.
- Copier-coller entre projets, styles réutilisables, palettes de marque.
- Glisser-déposer depuis la Bibliothèque vers le canevas : utilisez le double-clic.

## Son

- Enregistrer le micro dans ANTARES : importez un fichier enregistré ailleurs.
- Marqueurs sur la forme d'onde, atténuation automatique de la musique sous la voix (*ducking*), normalisation.

## Sciences

- Simulation à N corps, champs de vecteurs, tableaux et matrices dans les équations, écriture progressive d'une formule.
- Échelle logarithmique, histogrammes et plusieurs courbes par graphique.

## 3D

- Import de modèles glTF/GLB, caméra animée, rendu GPU : seule la planète procédurale avec Blender est disponible.

## Distribution

- Installateur Windows signé : la version Windows est un dossier à décompresser.
- Validation complète sur Windows 11 par un utilisateur : en cours.
- Traductions autres que le français.

La liste à jour se trouve dans le fichier `docs/PROJECT_STATUS.md` du projet.
