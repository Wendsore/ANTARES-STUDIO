## Gestes propres aux panneaux

| Où | Touche ou geste | Effet |
|---|---|---|
| Canevas | flèches (Maj : ×10) | déplacer la sélection |
| Canevas | Échap | désélectionner |
| Canevas | molette ; clic molette ou Alt + glisser | zoom ; déplacer la vue |
| Canevas | Maj pendant un redimensionnement ou une rotation | proportions conservées ; pas de 15° |
| Timeline | molette ; Ctrl + molette | défiler ; zoom temporel |
| Timeline | ← → | image précédente / suivante |
| Timeline | Suppr | supprimer la clé sélectionnée |
| Export | Échap | annuler l'export en cours |
| Recherche de commandes | ↑ ↓, Entrée, Échap | choisir, exécuter, fermer |

Les touches sont indiquées pour un clavier de PC ; sur Mac, Ctrl correspond à ⌘.
