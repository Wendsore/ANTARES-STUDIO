# Icônes de l'interface

- `*.svg` sauf `antares-logo.svg` : sous-ensemble de **Lucide** `lucide-static` 1.51.0
  (https://lucide.dev, archive npm vérifiée par son empreinte SHA-512 le 2026-10-22), licence ISC ;
  certaines icônes dérivent de Feather (MIT). Texte complet : `LICENSE-lucide.txt`.
  Les fichiers sont copiés sans modification ; la couleur `currentColor` est remplacée au chargement
  par la couleur du thème (`antares_studio/app/icons.py`).
- `antares-logo.svg` : logo dessiné pour ANTARES Studio (étoile supergéante rouge au foyer d'une orbite
  elliptique). Il suit la licence du projet, non encore décidée (R-002).
